# Licensing decision and scope

[English](LICENSING_DECISION.md) · [Português](LICENSING_DECISION.pt-BR.md)

The owner selected **GNU GPL v3.0 only** (`GPL-3.0-only`) for original project
work. The complete, unmodified license text is in [LICENSE](../LICENSE). This
decision covers original code, configuration, Node-RED flows, scripts, and
documentation. It permits private use without publication. Distribution of a
covered modified version requires corresponding source and the required
notices for its recipients under the GPL; it does not require a public GitHub
fork or publication to everyone. Forks and upstream contributions are encouraged.

The root license does not replace the copyright and licenses of vendored
third-party code. Alexa Media Player and Home Assistant Core resources retain
Apache-2.0; HACS and Kia Uvo retain MIT. Their upstream `LICENSE.upstream`
files and attribution remain in place, including for local modifications.
Managed npm dependencies and container images also retain their own terms.
See [third-party notices](../THIRD_PARTY_NOTICES.md) and
[dependency provenance](DEPENDENCY_PROVENANCE.en.md).

The GitHub template setting was previously observed as enabled. A fork is the
preferred way to propose changes to this repository, but the GPL does not
impose a hosting platform or a public-fork requirement. This document records
the selected license; it does not assert ownership of upstream code.
