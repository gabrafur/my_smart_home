# Evidência histórica — schema v1

Esta pasta preserva, sem reinterpretação, os artefatos publicados pela execução
Local AI de 24/08/2026 (`local-ai-high-potential-v1`). O `latest.json` v2 na pasta
pai foi recalculado a partir destes resultados por caso e eventos; nenhuma nova
inferência RTX ou chamada GPT foi feita na migração.

Os arquivos v1 continuam auditáveis, mas sua terminologia e alguns denominadores
são legados. Em particular, `critical_errors=25` representa casos selecionados
com ao menos uma flag crítica, não a quantidade de ocorrências categóricas.

Documentos preservados: [relatório gerado](report.md) e
[relatório técnico](technical-report.md).

para a nova pasta; JSON, CSV, eventos e relatório gerado permanecem inalterados.
