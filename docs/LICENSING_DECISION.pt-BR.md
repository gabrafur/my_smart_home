# Decisão sobre licença e escopo

[English](LICENSING_DECISION.md) · [Português](LICENSING_DECISION.pt-BR.md)

O proprietário escolheu **GNU GPL v3.0 somente** (`GPL-3.0-only`) para o
trabalho original do projeto. O texto integral e inalterado está em
[LICENSE](../LICENSE). A decisão cobre código, configuração, fluxos Node-RED,
scripts e documentação originais. Uso privado não exige publicação. A
distribuição de versão modificada coberta exige código-fonte correspondente e
os avisos obrigatórios aos destinatários sob a GPL; não exige fork público no
GitHub nem publicação para toda a comunidade. Forks e contribuições upstream
são incentivados.

A licença raiz não substitui direitos autorais nem licenças de código de
terceiros vendorizado. Alexa Media Player e recursos do Home Assistant Core
permanecem sob Apache-2.0; HACS e Kia Uvo, sob MIT. Seus arquivos
`LICENSE.upstream` e atribuições permanecem, inclusive nas modificações
locais. Dependências npm e imagens de container também mantêm termos próprios.
Consulte os [avisos de terceiros](../THIRD_PARTY_NOTICES.pt-BR.md) e a
[proveniência](DEPENDENCY_PROVENANCE.md).

O controle de template do GitHub havia sido observado como habilitado. Um
fork é o caminho preferido para propor alterações a este repositório, mas a
GPL não exige plataforma de hospedagem nem fork público. Este documento
registra a licença escolhida; não declara titularidade de código upstream.
